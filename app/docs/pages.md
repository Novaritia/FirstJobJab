# FirstJobJab — หน้าเว็บทั้งหมด

แต่ละหน้าทำอะไร ใช้ API ไหน (รายละเอียด API ดู [`../API.md`](../API.md))

## สาธารณะ (ไม่ต้องล็อกอิน)

| หน้า | หน้าที่ | API |
|---|---|---|
| `/` **Landing** | อธิบาย product ในหน้าเดียว ตัวอย่าง statement ถูกตรวจยอดทีละแถวแล้วกลายเป็นแผน + 3 ขั้นตอนการใช้งาน ปุ่มสมัคร / เข้าสู่ระบบ | — |
| `/register` **สมัครสมาชิก** | สร้างบัญชีด้วยอีเมล รหัสผ่าน ชื่อที่แสดง แล้วพาไป onboarding | `POST /auth/register` |
| `/login` **เข้าสู่ระบบ** | ล็อกอินด้วยอีเมล/รหัสผ่าน มีปุ่ม "ลองด้วยบัญชี demo" (ใน dev/demo) | `POST /auth/login` |

## หลังล็อกอิน — เมนูจัดเป็น 4 กลุ่ม

### ภาพรวม
| หน้า | หน้าที่ | API |
|---|---|---|
| `/dashboard` **ภาพรวม** | หน้าแรกหลังล็อกอิน: เงินเข้า / ออก / คงเหลือสุทธิของเดือน, ตารางใช้จ่ายตามหมวด, เทียบ 3 เดือน, **🔥 ไฟอัปเดต** (+1 ทุกครั้งที่มีข้อมูลใหม่ ไม่มีเพดาน, "อัปเดตครั้งถัดไปภายใน X วัน ไม่งั้นไฟดับ" — เหลือง ≤7 วัน แดง ≤2 วัน) + **ประวัติต่อเนื่อง x/6 เดือน** สำหรับยื่นกู้ พร้อมแถบเดือนที่ขาด statement, สรุปเป็นภาษาคน, ปุ่มฟังสรุปเสียงรายสัปดาห์, รายการ "สิ่งที่ควรทำ" | `/insights/summary`, `/streak`, `/voice/weekly` |
| `/assistant` **ผู้ช่วย** | ถามอะไรก็ได้เกี่ยวกับบัญชีตัวเอง สลับได้ 2 โหมด: **แชท** (พิมพ์ถาม มีคำถามแนะนำ ตอบพร้อมตารางข้อมูล) และ **เสียง** (กดพูด → ElevenLabs ถอดเสียง → AI ตอบ → อ่านออกเสียง) | `POST /chat`, `POST /chat/voice` |

### ข้อมูล
| หน้า | หน้าที่ | API |
|---|---|---|
| `/upload` **อัปโหลด** | ส่ง statement PDF (มี text หรือภาพสแกน) และรูปสลิป ลากวางได้หลายไฟล์ → **หน้าตรวจยอด**: ✅ แถวที่ยอดคงเหลือตรง / ⚠️ แถวที่ไม่ตรง (แก้ได้เฉพาะแถวนี้) → ยืนยัน → +1 🔥 (เฉพาะเมื่อมีรายการใหม่) · สลิป: ✅ ตรงกับ statement (ไม่นับซ้ำ) / ✋ กดยืนยันเพื่อเพิ่ม · ถ้า PDF ล็อกและปลดเองไม่ได้ จะถามรหัส | `/uploads`, `/uploads/:id/rows/:i`, `/uploads/:id/confirm`, `/slips`, `/slips/:id/confirm` |
| `/transactions` **รายการ** | ตารางรายการทั้งหมด (มือถือเป็นการ์ด) กรองตามเดือน, แก้หมวด/โน้ตได้ทันที, ซ่อนรายการ, เพิ่มรายการเอง (เช่นเงินสด), ป้าย ✅ จาก statement / ✏️ แก้ไขแล้ว / ✋ เพิ่มเอง, ดูประวัติการแก้ไขของแต่ละแถว, ดาวน์โหลด CSV | `/transactions`, `/transactions/:id`, `/transactions/:id/edits`, `/transactions/export.csv` |

### วางแผน
| หน้า | หน้าที่ | API |
|---|---|---|
| `/plan` **แผนเงิน** | กราฟเงินเติบโต ลากปรับ: ออมเดือนละเท่าไหร่ / ผลตอบแทน % / กี่ปี + แนะนำการแบ่งเงินเดือนเป็น ใช้จ่าย / เงินฉุกเฉิน / ลงทุน จากรายจ่ายจริง | `POST /insights/growth`, `/insights/summary` |
| `/tax` **ภาษี** | ประมาณภาษีเงินได้บุคคลธรรมดาปีนี้ แสดงที่มาทีละขั้น (เงินได้ → ค่าใช้จ่าย → ลดหย่อน → ขั้นบันได) + "เริ่มเสียภาษีเมื่อเงินเดือนถึง ฿X" · ประมาณการ ไม่ใช่คำแนะนำทางภาษี | `/insights/tax` |
| `/loan-ready` **พร้อมกู้** | ความคืบหน้าประวัติต่อเนื่อง x/6 เดือน, รายรับ/รายจ่ายเฉลี่ย, ผ่อนได้ไม่เกินเดือนละเท่าไหร่ (หลักทั่วไป 40% ของรายได้ ไม่ใช่เกณฑ์ธนาคาร) | `/insights/loan-ready` |

### บัญชี
| หน้า | หน้าที่ | API |
|---|---|---|
| `/onboarding` **เริ่มต้นใช้งาน** | 3 ขั้น: ① ความยินยอม PDPA แยกตามจุดประสงค์ ② วันเกิด + เลขบัตรประชาชน (ใช้ปลดล็อก PDF ธนาคารเท่านั้น เข้ารหัสเก็บ ข้ามได้) ③ ชวนอัปโหลด statement ย้อนหลัง 3–6 เดือน | `/profile/consents`, `/profile/pii` |
| `/settings` **ตั้งค่า** | เปิด/ปิดความยินยอม, แก้ข้อมูลปลดล็อก PDF, ดู log การใช้งานบัญชีตัวเอง (audit), ออกจากระบบ | `/profile/*`, `/audit`, `/auth/logout` |

## Responsive
- **Desktop:** sidebar ซ้ายจัดกลุ่ม, หัวเพจมีชื่อ + ปุ่มหลักด้านขวา
- **iPad:** sidebar ย่อเป็นไอคอน กดขยายได้
- **มือถือ:** แถบบน + tab bar ล่าง, ตารางกลายเป็นรายการแนวตั้ง
